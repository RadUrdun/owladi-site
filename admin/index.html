One-time setup

  1. Go to github.com/settings/personal-access-tokens/new.
  2. Under "Repository access", choose "Only select repositories" and pick RadUrdun/owladi-site.
  3. Under "Permissions" → "Repository permissions", set Contents to Read and write.
  4. Generate the token, copy it, and paste it below. It's stored only in this browser (localStorage), never sent anywhere except GitHub.
